LabVnua is a Flutter student academic companion for Vietnam National University of Agriculture. It demonstrates API integration, SQLite caching, local notifications, Supabase realtime chat, QR scanning, and Gemini-powered assistant functionality in a feature-first mobile codebase.

Use this repository as a portfolio example for Flutter development, mobile architecture, local data persistence, and full-stack integration work.
