# Test Workflow

1. Identify the target module, expected behavior, environment, and test role.
2. Load target requirements and only relevant implementation/API/database context.
3. Read up to three relevant worklogs from `.agent/worklogs/TEST/`.
4. Read `.agent/skills/index.md`, then only matching test skills.
5. Create or update one test checklist under `docs/checklists/test/`.
6. Define positive, negative, and regression cases.
7. Execute tests and record exact outcomes.
8. Create or link a bug checklist for confirmed failures.
9. Update checklist, then worklog, then skill index.
