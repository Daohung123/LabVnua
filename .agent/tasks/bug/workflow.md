# Bug Workflow

1. Identify `SCOPE`, symptom, expected behavior, and reproduction steps.
2. Load nearest bug worklogs, issue/checklist, and expected-behavior source.
3. Reproduce before changing code whenever feasible.
4. Trace the smallest confirmed root cause.
5. Fix only the confirmed cause and required related code.
6. Verify the original repro, a relevant edge case, and a regression flow.
7. Update the bug checklist, then worklog, then skill index.
